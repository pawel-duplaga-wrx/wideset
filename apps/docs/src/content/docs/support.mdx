| You have                 | Go to                                                                                                         |
| ------------------------ | ------------------------------------------------------------------------------------------------------------- |
| A question, an idea      | [GitHub Discussions](https://github.com/widelab-co/wideset/discussions)                                       |
| A bug                    | [GitHub Issues](https://github.com/widelab-co/wideset/issues/new/choose)                                      |
| A security vulnerability | [Report it privately](https://github.com/widelab-co/wideset/security/advisories/new), never in a public issue |

Before you ask:

- Check [What's new](/docs/whats-new): the behaviour may have changed on purpose.
- Look at the component's page and its examples; a component's props table lists every option.
- Search existing issues and discussions.

With a bug, include the package version (`npm ls @wideset/react`), your React version and
bundler, and a minimal reproduction.
