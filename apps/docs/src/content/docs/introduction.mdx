## Start here

- **[Installation](/docs/installation)**: install the package and update through semver.
- **[CLI](/docs/cli)**: copy a component's source into your repo and own it.

## How it works

- **Tokens.** Every visual value is a CSS variable, and every class carries `ws` (`p-ws-4`). See
  [Theming](/docs/theming).
- **Composition.** Components expose their parts instead of configuration props:
  `<Button><Button.Icon icon={RiCheckLine} /></Button>`.
- **Figma.** The design file is the source of truth, and the code matches it.
