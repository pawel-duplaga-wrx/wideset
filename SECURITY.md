# Security policy

## Reporting a vulnerability

Do not open a public issue. Report it privately through
[GitHub's private vulnerability reporting](https://github.com/widelab-co/wideset/security/advisories/new)
with a description, the affected versions and, if you can, a reproduction.

We aim to acknowledge a report within five working days and to tell you what happens next.
Once a fix is released, the advisory is published with credit to you unless you ask otherwise.

## Supported versions

Fixes go into the latest minor release of `@wideset/react`. Upgrade to it to get them.
